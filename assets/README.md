# Icon

The registry icon (`icon.svg`, and `icon.png` at 256 × 256 for directories that don't show SVG) follows the author's "Ink & One Line" logo language: manga ink, one object split into a paper half and an ink half, exactly one coloured line.

```text
App name:        Austria Property
What it does:    Works out Austrian property purchase costs, buy-to-let returns, tax and rent caps, cited to the statute.
The object:      A gabled house
The two halves:  Left half paper with hatching on its lower part, right half ink with gloss strokes
The one line:    The base the house stands on: the bottom line the calculation produces
Line colour:     #d01c34 (Austrian red; 5.4:1 against paper, 3.4:1 against ink)
Dusk tile:       #7f6f72 → #e8d5d6
Tilt:            0 (a tilted house reads as falling over)
Impact marks:    yes
```
